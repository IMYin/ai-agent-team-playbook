# Task contract (write before starting)

```
## Task contract: <short name>
- Goal: one sentence
- Inputs: where the material comes from
- Output: what gets delivered, and where
- Done when: how to verify (commands / checklist)
- Out of scope: what you're explicitly not doing
- Needs owner OK: any action from TEAM.md section 2
- Risks: where this might get stuck
```

No contract, no work. If the scope changes, update the contract first.
