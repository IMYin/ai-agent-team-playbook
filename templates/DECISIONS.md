# Owner decisions

> Only things the owner explicitly confirmed go here. Agents ask before changing any of them.

## Format
```
### D<number> <decision>
- Confirmed by: owner
- Why:
- Affects:
- Expires: (or "permanent")
```

## Example (fictional)
### D1 Two posts a week, max
- Confirmed by: owner
- Why: fewer, better posts
- Affects: writer, publisher
- Expires: permanent
