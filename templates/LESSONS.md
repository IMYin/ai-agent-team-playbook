# Lessons

> Every time the owner corrects an agent, that agent appends one entry here. All agents read the whole file before work.

## Format
```
### L<number> <one-line rule>
- Applies to: whole team / <agent>
- What happened: one or two sentences, no blame
- From now on: exactly what to do
- How to check: what to look at before delivering
```

## Examples (fictional)

### L1 "Tested" means paste the command and output
- Applies to: whole team
- What happened: an agent reported "tested", but had only run part of the suite
- From now on: paste the exact command and the last lines of output in the receipt
- How to check: no output in the receipt = not done

### L2 Ask in HANDOFF before editing someone else's file
- Applies to: whole team
- What happened: two agents edited the same config at once; the later write wiped the earlier one
- From now on: post "I want to change X" in HANDOFF and wait for the owner of X
- How to check: every file in the receipt is yours, or there's a recorded OK

### L3 One exclamation mark per headline, max
- Applies to: writer agent
- What happened: a headline with three exclamation marks got called out as overhyped
- From now on: at most one
- How to check: search the draft for "!!" before handing off
