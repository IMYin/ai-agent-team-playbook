# Handoff log

> Append only. Never edit past entries. Newest at the bottom.

## Format
```
- <time> <agent> → <recipient / team>: <what was done / what's needed>. Receipt: <link or path>. Open: <if any>
```

## Examples (fictional)
- Mon 09:10 writer → reviewer: first draft of "Getting Started" is in drafts/, please review. Open: no images yet
- Mon 11:30 reviewer → writer: sent back, the example in section 2 doesn't run. Notes in reviews/
- Mon 15:00 writer → publisher: revised draft passed review, receipt in receipts/. Open: waiting on owner to pick a publish time
